# 台灣 NCD 經濟指標 (`"tw_eco"`)

國家發展委員會景氣偵測系統經濟指標。使用 Selenium 網頁爬蟲，需要 Chrome 瀏覽器。

資料來源: https://index.ndc.gov.tw/n/zh_tw/data/eco#/
資料範圍: 1982-01 至今，每月更新

## 安裝

```bash
pip install -e ".[stooq]"
```

## Symbols

| Symbol | 說明 |
|--------|------|
| `景氣對策信號(燈號)` | 景氣燈號 |
| `景氣對策信號(分)` | 景氣對策信號綜合分數 |
| `領先指標綜合指數(點)` | 領先指標綜合指數 |
| `領先指標不含趨勢指數(點)` | 領先指標不含趨勢 |
| `同時指標綜合指數(點)` | 同時指標綜合指數 |
| `同時指標不含趨勢指數(點)` | 同時指標不含趨勢 |
| `落後指標綜合指數(點)` | 落後指標綜合指數 |
| `落後指標不含趨勢指數(點)` | 落後指標不含趨勢 |

## 參數

| 參數 | 說明 |
|------|------|
| `start` / `end` | 日期格式 `YYYY-MM` 或 `YYYY-MM-DD` |

`sub_field` 和 `frequency` 不適用。

## 使用範例

```python
from financial_data_query import query

# 查詢景氣綜合分數
result = query("tw_eco", "景氣對策信號(分)")

# 指定日期範圍
result = query("tw_eco", "景氣對策信號(分)", start="2020-01", end="2024-12")

# 批量查詢多個指標
result = query("tw_eco", ["景氣對策信號(燈號)", "領先指標綜合指數(點)"])
```

## 回傳欄位

`date`（月終）, `value`

## 注意事項

- 每次查詢會開啟瀏覽器抓取全量資料，然後在客戶端篩選
- 批量查詢不會重複開啟瀏覽器（共用同一張表）
