# 台灣 NCD PMI (`"tw_pmi"`)

國家發展委員會採購經理人指數。使用 Selenium 網頁爬蟲，需要 Chrome 瀏覽器。

資料來源: https://index.ndc.gov.tw/n/zh_tw/data/PMI#/
資料範圍: 2012-07 至今，每月更新

## 安裝

```bash
pip install -e ".[stooq]"
```

## Symbols

### 原始值

| Symbol | 說明 |
|--------|------|
| `製造業PMI` | 製造業 PMI 原始值 |
| `新增訂單數量` | 新增訂單數量指數 |
| `生產數量` | 生產數量指數 |
| `人力僱用數量` | 人力僱用數量指數 |
| `供應商交貨時間(%)` | 供應商交貨時間百分比 |
| `存貨(%)` | 存貨百分比 |
| `客戶存貨(%)` | 客戶存貨百分比 |
| `原物料價格(%)` | 原物料價格百分比 |
| `未完成訂單(%)` | 未完成訂單百分比 |
| `新增出口訂單(%)` | 新增出口訂單百分比 |
| `進口原物料數量(%)` | 進口原物料數量百分比 |
| `未來六個月展望(%)` | 未來六個月展望百分比 |

| Symbol | 說明 |
|--------|------|
| `製造業PMI(季調值)(%)` | 製造業 PMI 季調值 |
| `新增訂單數量(季調值)(%)` | 新增訂單數量季調值 |
| `生產數量(季調值)(%)` | 生產數量季調值 |

## 參數

| 參數 | 說明 |
|------|------|
| `start` / `end` | 日期格式 `YYYY-MM` 或 `YYYY-MM-DD` |

`sub_field` 和 `frequency` 不適用。

## 使用範例

```python
from financial_data_query import query

# 查詢製造業 PMI
result = query("tw_pmi", "製造業PMI")

# 指定日期範圍
result = query("tw_pmi", "製造業PMI", start="2020-01", end="2024-12")

# 批量查詢
result = query("tw_pmi", ["製造業PMI", "新增訂單數量", "生產數量"])
```

## 回傳欄位

`date`（月終）, `value`

## 注意事項

- 每次查詢會開啟瀏覽器抓取全量資料，然後在客戶端篩選
- 批量查詢不會重複開啟瀏覽器（共用同一張表）
